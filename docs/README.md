与 `AGENTS.md` 的按需阅读表同构；本表只做反向入口，细节一律链到各文档锚点，
不在此重复维护。

## 文档约定

- **用语分级**：必须/不得 = 硬约束，违反即缺陷；应/不应 = 默认做法，偏离需写明理由；可 = 允许。
- **给人读的**：一个主题一篇文档 + 文首目录；**给 agent 读的**：一主题一节、写明何时读、
  标题锚点可被 AGENTS.md 精确链接（新增章节时同步检查 AGENTS.md 链接有效性）。
- **一事一处**：每类问题只有一个权威出处（分工见上表）；发现同一规则出现在两处，合并到拥有它的文档。
- **整合不追加**：修改时改写拥有该主题的节，不在文末打补丁。
- **写规则不写过程**：历史与决策过程进 git；文档只留当前有效规则。
- **实测事实**（协议响应、寄存器、固件差异）只存于 initial-plan.md 附录；新增事实先实测再入册，
  并标注验证日期。不得把猜测写进附录。
