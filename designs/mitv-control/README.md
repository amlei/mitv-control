# MiTV 控制中心 — 交互原型（baoyu-design）

> 预览：`python3 -m http.server 4311 --directory designs` → <http://localhost:4311/mitv-control/index.html>
> 方法：JimLiu/baoyu-design（hi-fi + interactive-prototype）；文件结构遵循其 React+Babel 多文件约定。

## 假设与设计推理

- 按全幅 web 页面设计（不做窗口装饰、无红绿灯）：Electron 渲染层就是整个 web 区域，
  页头/设备切换/Tab/内容（限宽 920px 居中）/状态栏直接铺满视口。
- **左右布局**：左侧栏（品牌 / 设备切换 / 功能导航 / 主题与状态）+ 右侧内容区（限宽居中），
  避免上下堆叠菜单挤占纵向空间；侧栏内**不用任何分割线**，靠「显示器 / 功能」小节标题与
  选中态分层，整体融合在一张连续表面上。窄窗口（<720px）侧栏自动折行到顶部。
- 用户唯一美学要求：**简约、简单、直接**。因此放弃卡片瀑布流，改为「先选显示器，再操作」：
  顶部设备 pill 切换两台显示器，下方功能 Tab 只展示当前设备支持的项，缺通道的 Tab
  直接置灰并以 title 说明原因（对应 repo-conventions 的「置灰必须给原因」）。
- **应用不内置 AI**：不设 AI 聊天界面；Agent 接入以 **CLI 子命令 + MCP Server** 形式暴露，
  在「设置 → Agent 接入」展示 tools、CLI 示例与 mcpServers 配置（可复制）。
- 全功能呈现（原型先行，不等 P0/P1/P2 分期）：快捷 / 遥控 / 画面 / 游戏 / 灯效 / 预设 / 设置
  全部设计并交互可用；原型中的禁用项只代表「该设备通道不支持」，不代表「未实现」。
- 数值全部取自 2026-10-24 真机实测（G Pro 背光 56、音量 21、5K 亮度 82、精密控光关等），
  见 `docs/design/initial-plan.md` 附录。
- 状态真源原则在 UI 的体现：操作提交后出现「已应用 · 已验证」toast；**滑条拖动中只更新本地值，
  松手才提交一次**（避免 apply/toast 风暴）；滑条永远显示最后确认写入值。
- 危险操作（电源 / 信号源 / 恢复默认 / 320Hz EDID）一律**居中弹窗**二次确认，
  文案遵循 `docs/repo-conventions.md#界面文案` 的确认模板。
- 深色为默认主题（媒体工具场景），右上角可切浅色；品牌色仅一个橙色 accent。

## 信息架构

```
页面（全幅 web，Electron 直接承载；左右布局）
├─ 侧栏：品牌 · 显示器组（G Pro 27U「米显」6095+ADB | 小米 5K 仅 DDC）· 功能组 · 主题/状态
│    （无分割线，小节标题 + 选中态分层；窄窗口自动折到顶部）
├─ 内容区（右侧，限宽居中，随导航切换）
│   ├─ 快捷：亮度 / 音量+静音 / 信号源 / 电源（5K 仅亮度）
│   ├─ 遥控：方向+OK / 音量± / 主页·返回·菜单·电源
│   ├─ 画面：模式 / 六项画质滑条 / 色温·精密控光·动态清晰度·响应时间·色域 / 恢复默认
│   ├─ 游戏：FreeSync / 准星 / 动态准星 / 狙击镜 / 夜视 / FPS / 320Hz（EDID 弹窗确认）
│   ├─ 灯效：总开关 / 模式 / 颜色 / 亮度 1-15 / 照明色温
│   ├─ 预设：三个示例场景 + 新建 + 自动任务（23:00-07:00）
│   └─ 设置：外观(主题) / 设备(→详情页：基本信息/三通道状态/危险区) / ADB 连接向导 / Agent 接入(CLI·MCP) / 手机远程(地址+令牌) / 快捷键 / 关于
├─ 危险操作 → 居中确认弹窗（遮罩）
└─ 状态栏：各设备通道摘要 + 电源状态
```

## 实现说明

- `index.html`（入口 + 全部设计 token 与组件样式）+ `icons.jsx` / `data.jsx` / `panes.jsx` / `app.jsx`。
- 滑条为「本地值 + 松手提交」模式（panes.jsx Slider），是状态真源设计的 UI 侧对应物。
- 本页为开发用多文件原型（需 HTTP 服务）；交付单文件版时用 save-as-standalone-html 流程另出。

## 待用户确认的开放点
